# DEVIATIONS

Every change from CLAUDE.md / the paper protocol: what, why, impact. These feed the report's limitations.

- (pre-filled) Paper 'full' size uses 50% of the repo pool for Abalone, Adult, BreastCancer, Churn, HeartDisease (likely explanation of BC 181/45/114; unconfirmed).
- **Phase 0, paper_reference_numbers.csv:** all 88 Table 3 rows re-extracted from the PDF (page 17). One cell corrected: BreastCancer size 10 `pfnboost_se` 0.0013 -> 0.0020. All other existing rows matched; the missing dataset x size rows were added (`note = "added from PDF"`). `car` has no Table 3 row. Details in `docs/paper_reference_numbers.README.txt`.
- **Phase 0, environment (Mac, Option B):** this phase ran on a MacBook (Apple Silicon, CPU only), not the lab PC. Env `p012` is a clone of the working `llmboost-run` env plus optuna 3.5.0, pytest, pyyaml, seaborn, matplotlib<3.10, jupyter. It keeps that env's **numpy 1.26.2** (pin 1.26.4) and **scipy 1.15.2 from conda-forge** (pin <1.14): the pip scipy 1.13.1 wheel fails to import on this macOS (TypeError in `scipy.interpolate._fitpack_impl`). `scripts/00_check_env.py` checks numpy < 2 instead of the exact pin. Impact: none expected on results; the lab-PC env with exact pins may differ in the last digits. TabPFN checkpoint copied from `llmboost-run` (`prior_diff_real_checkpoint_n_0_epoch_100.cpkt`).
- **Cache path:** `results/cache/tabpfn/<protocol>/<dataset>/<size>/<seed>/<mode>.npz` has an extra `<protocol>` level (CLAUDE.md 4.2 has none), because hold-out A, hold-out B, CV folds and the sweep produce different splits for the same dataset and seed.
- **Binary ECE** is computed on P(positive class) with 15 equal-width bins; multiclass ECE on the top-class confidence (CLAUDE.md 4.8 fixes only the multiclass case).
- **Positive class (minority rule, CLAUDE.md 4.8):** BreastCancer `M` (config). Minority class picked: Adult "greater than 50K", Churn/HeartDisease/bank/blood/calhousing/diabetes "yes", Statlog `1`, Sharktank/creditg/heart/jungle "no" (see `results/tables/T1_datasets.csv`). AUC does not depend on this choice; precision/recall/F1 do.
- **Sweep sampling, Wine full:** the paper's 113+28 = 141 of 142 pool rows leaves 1 row to drop, fewer than the 3 classes, so that single dropped row is chosen at random; the train/val split itself is still stratified.
- **Data quirk:** Adult's shipped CSVs have duplicate index values; rows are re-indexed by position. bank/blood/car test-set class shares differ from the pool's (shipped split, kept as is).
